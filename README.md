## 🧩 Overview

**absentDb** is a versatile, open-source platform tailored for school management, combining real-time data updates, secure authentication, and modular architecture to streamline administrative workflows.  
Its flexible design allows developers to build engaging, efficient educational systems with ease.

### Why absentDb?

This project aims to simplify school management by providing a comprehensive, customizable solution.  
The core features include:

- 🧱 **Modular Architecture:** Easily extend and customize components like attendance, payments, and user management.  
- 🔄 **Real-Time Data:** Fetch and display live weather updates and currency exchange rates for a dynamic dashboard experience.  
- 🔐 **Secure Authentication:** Manage user sessions securely with role-based login and session control.  
- 📊 **Interactive Dashboard:** Visualize operational insights and streamline administrative tasks.  
- 🧩 **API Integration:** Access class and student data seamlessly through dedicated endpoints.
